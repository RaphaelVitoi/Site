# ARQUITETURA DO CÉREBRO HÍBRIDO (Web <-> Local)

> **Status:** Ativo e Integrado (Workflow v6.0)
> **Objetivo:** Maximizar a capacidade cognitiva (Estado da Arte) enquanto minimiza o consumo energético (Fricção do Usuário e Custo de API).

## O Paradigma

O Ecossistema Nexus deixou de ser apenas um roteador de terminal para se tornar o **Hemisfério Direito** (Execução) de um cérebro muito maior, onde as assinaturas Web Pro de Raphael Vitoi atuam como o **Hemisfério Esquerdo** (Cognição).

### Hemisfério Esquerdo (A Nuvem / Macro-Cognição)
*   **Plataformas:** Claude Pro (Web/Projects) e Gemini Advanced (Web/2M Context).
*   **Agentes Residentes:** @maverick (Estratégia Pura), @planner (Arquitetura Densa), @pesquisador (Análise de Dados Massiva).
*   **Função:** Raciocínio profundo, ideação, debate filosófico, análise de PDFs pesados e criação de Especificações Técnicas (SPECs).
*   **Vantagem:** Custo marginal zero (assinatura fixa), janelas de contexto ilimitadas, interface visual rica (Artifacts).

### Hemisfério Direito (O Nexus / Micro-Execução)
*   **Plataformas:** Terminal PowerShell, Python Task Executor, VS Code.
*   **Agentes Residentes:** @implementor (God Mode), @verifier (Testes), @skillmaster (Servidor/Manutenção), @auditor.
*   **Função:** Materialização da realidade. Ler as SPECs geradas pelo Hemisfério Esquerdo e usar a Autorização Suprema (God Mode 2.0) para rodar scripts, baixar pacotes NPM e criar/editar os arquivos físicos no HD.
*   **Vantagem:** Acesso direto ao sistema de arquivos de Raphael, execução autônoma, auto-cura (Autodebugger). Custo de API irrisório, pois a IA não precisa "pensar" do zero, apenas "executar" a planta.

## O Protocolo "Bridge" (A Ponte de Redução de Fricção)

Para que Raphael não gaste energia traduzindo comandos entre os hemisférios, o protocolo **Bridge** foi estabelecido.

**O Ciclo Operacional:**
1. Raphael gera uma SPEC arquitetural complexa no Claude Pro (Web).
2. Raphael salva essa SPEC no projeto (ex: `docs/tasks/nova_feature.md`).
3. Raphael executa o comando nativo no terminal: `nexus-bridge docs/tasks/nova_feature.md`.
4. **Automágico:** O Nexus aciona o @implementor com diretrizes estritas para devorar o arquivo especificado, rodar os comandos de terminal necessários e forjar os arquivos no código, transferindo o pensamento abstrato da Web para o código funcional local.

## Consciência Sistêmica
Todos os agentes locais estão cientes de que são a "mão que constrói" e não precisam reinventar a roda se uma SPEC já foi fornecida pelo Hemisfério Esquerdo. A reverência à SPEC fornecida é absoluta.
