### Executando Autocorrecao e Backup

Primeiro, vou gerar um timestamp dinamico para o nome do diretorio de backup, seguindo o formato `YYYY-MM-DD_HHmmss` para consistencia.

```powershell
$timestamp = Get-Date -Format "yyyy-MM-dd_HHmmss"
$backupDirectoryName = "full_backup_$timestamp"
$backupPath = "backups/$backupDirectoryName"

Write-Host "Criando diretorio de backup: $backupPath"

# Comando para criar o diretorio de backup (corrigido para PowerShell)
New-Item -ItemType Directory -Path "$backupPath" -Force

Write-Host "Diretorio de backup criado com sucesso."
Write-Host "Iniciando copia dos arquivos do projeto para $backupPath..."

# Comando para copiar os arquivos do projeto para o diretorio de backup
# .           -> Origem (diretorio atual, assumindo que e a raiz do projeto)
# $backupPath -> Destino (o diretorio de backup recem-criado)
# /E          -> Copia subdiretorios, incluindo vazios
# /COPYALL    -> Copia todas as informacoes de arquivo (atributos, carimbos de data/hora, seguranca, proprietario, auditoria)
# /DCOPY:T    -> Copia os carimbos de data/hora dos diretorios
# /XF "*.log" -> Exclui todos os arquivos com extensao .log (geralmente logs temporarios)
# /XD "backups" -> Exclui o proprio diretorio 'backups' para evitar copia recursiva
# /NFL        -> Nao lista os nomes dos arquivos
# /NDL        -> Nao lista os nomes dos diretorios
robocopy . "$backupPath" /E /COPYALL /DCOPY:T /XF "*.log" /XD "backups" /NFL /NDL

Write-Host "Backup de 'tudo que fizemos hoje' concluido com sucesso em $backupPath."
```
