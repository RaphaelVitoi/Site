## 2025-02-23 - Flattening 2D arrays in hot loops
**Learning:** In high-frequency mathematical hot loops like the Monte Carlo simulation, using multi-dimensional standard arrays (`number[][]`) creates massive GC churn and object allocation overhead. Combining this with nullish coalescing (`?? 0`) creates further branching overhead in V8.
**Action:** Replace 2D arrays with flat 1D TypedArrays (e.g., `Uint32Array(rows * cols)`). Access indices using math (`row * cols + col`). Additionally, cast known dense array accesses to `number` instead of falling back with `?? 0` to skip type-checking branches during execution.
