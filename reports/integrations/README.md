# Relatorios de integracoes externas

Esta pasta guarda fotografias operacionais de integracoes mantidas por
sincronizadores do repositorio. A Triade (Jules, Stitch e Exa) escreve seus relatorios aqui;
os geradores e skills apontam para estes caminhos:

- `JULES_REPORT.md`: Telemetria, sessoes assincronas e PRs do Google Jules Cloud.
- `STITCH_REPORT.md`: Telas, modelos (Gemini 3.8 Flash / 3.5 Flash-Lite) e tokens Obsidian Analytics do Google Cloud Stitch MCP.
- `EXA_REPORT.md`: Busca semantica, web fetch e pesquisa autonoma Exa Agent via Exa MCP.

Os relatorios registram o momento em que foram gerados. Para afirmar estado
atual, execute a verificacao correspondente e registre nova evidencia.
