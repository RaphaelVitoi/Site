# Revisao de ancora — pyproject.toml (extraPaths do python-backend)

## Contexto

O commit que toca `pyproject.toml` adiciona um unico item em
`[tool.pyright].extraPaths`:

```toml
"../extensions/sota-chrome-cockpit/python-backend",
```

Motivacao medida: arquivos do `python-backend` do `sota-chrome-cockpit` sao
abertos como arquivos soltos na workspace `Site` e o analisador estatico do
IDE os associava a esta configuracao; sem o extraPath, imports irmaos
(`cdp_cors_proxy`, `sota_loop`) reportavam `reportMissingImports`.

## Impacto

- Zero dependencia nova, zero pin alterado, zero script de build tocado.
- `extraPaths` e consumido exclusivamente por type checkers (pyright/
  basedpyright/Pylance); o runtime Python nao le esta secao.
- Nenhum caminho-ancora dos 46 registros VIGENTES e afetado em substancia:
  todos declaram `pyproject.toml` por historico de elevacao de dependencias
  e configs de tooling; este diff nao muda dependencia nem tooling.
