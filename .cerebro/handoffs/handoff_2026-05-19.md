**Data/Hora:** 19 de Maio de 2026

## Principais Realizações e Refatorações

1. **Blindagem do Transpiler (Jest/SWC):** Corrigida a falha de transpilação de arquivos TypeScript no frontend. O arquivo `jest.config.js` foi reajustado para utilizar `__dirname`, ancorando o Next.js SWC corretamente mesmo quando os testes são invocados a partir da raiz do monorepo.
2. **Correção do Motor Nash (Equação Unificada):** Fechamento do gap lógico no `nashSolver.ts`, aplicando a assimetria topológica (`deltaRp * 0.25`) ativamente na inércia defensiva do OOP (Risco de Ressurreição).
3. **Limpeza de Dívida Técnica (Backend & WASM):** Sanados alertas do Pylint e Ruff no `sota_integrity_test.py` (remoção de `assert` genéricos por exceções controladas, imports no topo) e eliminados "code smells" reportados pelo SonarLint no código WebAssembly gerado (`vitoi_equity_engine.js`).
4. **Resolução de Entropia Massiva no Frontend (Routing & Imports):** Tratamento cirúrgico de 166 erros do TypeScript em 52 arquivos gerados pela movimentação de pastas. Os caminhos foram redirecionados para a nova arquitetura centralizada em `src/components/ui/layout/`.
5. **Estabilização React 19:** Reversão do uso prematuro de `use(Context)` para `useContext(Context)` no `PostFlopPanel` e `RangeMatrix` para garantir a homeostase do linter e evitar quebras de build.

## Decisões Arquiteturais Tomadas

* Roteamento canônico do projeto agora centraliza componentes estéticos, estruturais e de navegação no diretório `ui/layout`.
* Foi adotada a supressão explícita (`// NOSONAR` e desabilitações de pylint) para arquivos de bindings automáticos do WASM, protegendo a API original contra quebras ao tentar conformar código C/Rust transpilado às regras de estilo do JavaScript.

## Invariantes Estabelecidas

* A base de código está com *Zero Erros* de compilação no TypeScript (Gatekeeper passou com sucesso).
* Toda invocação de testes deve herdar nativamente a configuração através de ponteiros absolutos de workspace, evitando fallback para o Babel padrão.
