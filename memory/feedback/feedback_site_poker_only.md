# feedback site poker only

O site e produto sao exclusivamente sobre poker. Nao ha espaco para componentes
de financas/startup (cap table, valuation pre/post-money, option pool).

**Why:** Raphael corrigiu quando a Fase 4 ia manter
IcmSimulator/IcmCapTable/IcmCharts como componentes validos. Este repo e o Poker

`project/project_site_identity.md`).

**How to apply:** Qualquer componente que nao seja diretamente relacionado a
poker (torneios, ICM, Risk Premium, Nash, ranges) deve ser questionado antes de
ser mantido ou criado.
